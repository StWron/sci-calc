# 과학·공학 계산 (sci-calc)

물성과 수치는 기억으로 답하지 말고 라이브러리로 계산해서 답한다. 이 스킬의 목적은 "발상"을 "검증된 숫자"로 바꾸는 것이다.

## 1. 시작: 설치 (매 대화 1회)

실행 환경은 대화마다 초기화되므로 계산 전에 먼저 실행한다.

```bash
bash <skill_dir>/scripts/setup.sh
```

`<skill_dir>`는 이 SKILL.md가 있는 폴더다. 모르면 `find /mnt/skills -name setup.sh -path '*sci-calc*'`로 찾는다. numpy, scipy, sympy, pandas, matplotlib은 기본 설치되어 있다.

## 2. 라이브러리 고르기

| 질문 유형 | 라이브러리 |
|---|---|
| 냉매·물·공기·암모니아 물성, 포화압력, 엔탈피 | CoolProp |
| 냉동·히트펌프 사이클 COP | `scripts/vcc.py` (CoolProp 기반) |
| 연소, 화염속도, 점화지연, NOx, 평형 조성 | Cantera |
| 배관 압력손실, 마찰계수, 밸브·피팅 | fluids |
| 열교환기 효율(ε-NTU), 대류 열전달 계수 | ht |
| 단위 환산, 단위 섞인 수식 | pint |
| 연립방정식, 최적화, 적분 | scipy |
| 기호 수식 정리, 관계식 유도 | sympy |

## 3. 자주 쓰는 패턴

**포화압력 / 물성**
```python
import CoolProp.CoolProp as CP
P = CP.PropsSI('P', 'T', 273.15+7.2, 'Q', 1, 'R1234yf')   # Pa
h = CP.PropsSI('H', 'T', 300, 'P', 4e5, 'R1234yf')        # J/kg
```
유체 이름 예: `R134a`, `R1234yf`, `R32`, `R410A`, `R290`, `R744`(CO2), `Ammonia`, `Water`, `Air`.

**사이클 COP**
```bash
python3 <skill_dir>/scripts/vcc.py R1234yf --te 7.2 --tc 50 --sh 5 --sc 5 --eta-is 0.7 --eta-motor 0.92 --q 2.3
```
등엔트로피 효율(`--eta-is`)은 결과를 크게 좌우하는 가정값이다. 소형 로터리·스크롤은 대략 0.6~0.75로 두고, 다른 값을 쓰면 근거를 밝힌다.

**연소 (암모니아·수소 혼소 화염속도)**
```python
import cantera as ct
gas = ct.Solution('gri30.yaml')   # 암모니아 정밀 계산은 암모니아 전용 메커니즘 권장
gas.set_equivalence_ratio(1.0, {'NH3':0.85,'H2':0.15}, {'O2':1,'N2':3.76})
gas.TP = 300, ct.one_atm
f = ct.FreeFlame(gas, width=0.03); f.solve(loglevel=0, auto=True)
print(f.velocity[0])   # m/s
```

## 4. 답변 규칙

- 가정(효율, 과열도, 조건)을 숫자와 함께 반드시 밝힌다. 가정값이 결과를 좌우하면 범위로 민감도를 보여준다.
- 물성표에서 바로 나오는 값(예: 포화압력)과 설계 성능을 가르는 값(예: 효율 가정에 따른 COP)을 구분해서 말한다.
- 이론 한계(카르노 COP 등)와 비교해 결과가 물리적으로 말이 되는지 점검한다.
- 결과를 묻는 질문에는 결론 숫자부터 말하고, 계산 과정은 짧게 붙인다.

## 5. 발상 결과의 물리 점검

sfumato·senato 같은 발상·심의 결과가 히트펌프, 열 수송·저장, 유체, 제어처럼 강하게 결합된 물리·열 루프를 다루면, 결론을 전달하기 전에 이 스킬로 핵심 주장을 숫자로 확인한다.

- 확인 대상: COP, 온도차, 유량, 압력손실, 열량 수지처럼 결론을 받치는 수치
- 이론 한계(카르노 COP, 에너지 보존)를 넘거나 가정값에 결과가 크게 흔들리면 그 사실을 결론 옆에 밝힌다
- 분야 간 유추는 운영·유인·도입 층에서 강하고, 물리 층에서는 숫자 확인 없이 채택하지 않는다
